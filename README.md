# Travel Memory Map

Travel Memory Map is a React + Leaflet travel diary app where users can save memories by address, view them as markers on an interactive map, edit/delete them from marker popups, and persist data in `localStorage`.

## Tech Stack

- React (Vite)
- JavaScript
- Tailwind CSS
- Leaflet + React Leaflet
- UUID
- OpenStreetMap Nominatim API



## Installation

make run

## Build for Production

make build
